# Лабораторная работа 6. REST API с SQLite

## Установка и запуск
1. Установите зависимости: `npm install`
2. Запустите сервер: `npm start`
3. Сервер будет доступен по адресу `http://localhost:3000`.

## Схема таблицы `tasks`
Таблица создается автоматически при запуске сервера.

| Поле | Тип | Описание |
| :--- | :--- | :--- |
| `id` | INTEGER | Первичный ключ (AUTOINCREMENT) |
| `title` | TEXT | Обязательное поле, заголовок |
| `description` | TEXT | Описание задачи (по умолчанию пустая строка) |
| `done` | INTEGER | Статус (0 = не выполнено, 1 = выполнено) |

## Список маршрутов

| Метод | URL | SQL | Успешный код | Ошибки |
| :--- | :--- | :--- | :--- | :--- |
| GET | `/api/tasks` | SELECT | 200 | — |
| GET | `/api/tasks/:id` | SELECT | 200 | 404 |
| POST | `/api/tasks` | INSERT | 201 | 400 |
| PATCH | `/api/tasks/:id` | UPDATE | 200 | 400, 404 |
| DELETE | `/api/tasks/:id` | DELETE | 204 | 404 |

## Примеры запросов

### Создание задачи (POST /api/tasks)
Тело запроса (JSON):
{ "title": "Сделать лабу", "description": "По интернет-технологиям" }

### Обновление (PATCH /api/tasks/1)
Можно передать только одно поле (например, отметить выполнение):
{ "done": true }

## Query-параметры (Фильтрация)
Выполняются через SQL `WHERE`.
- `GET /api/tasks?done=true` — только выполненные.
- `GET /api/tasks?q=лаба` — поиск по слову в названии (через `LIKE`).

## Правила валидации
- В методе `POST` поле `title` обязательно и не может быть пустым (иначе `400 Bad Request`).
- В методе `PATCH` нельзя очистить `title` (иначе `400 Bad Request`).

## Проверка сохранения после перезапуска
1. Создана задача через `POST` (получен ID).
2. Сервер остановлен (`Ctrl+C` в терминале).
3. Сервер запущен снова (`npm start`).
4. Выполнен `GET /api/tasks` — созданная задача на месте благодаря базе `data.db`.
