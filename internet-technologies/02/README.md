# Лабораторная работа 2. JavaScript, DOM и управление состоянием

## Файлы
- `index.html` — форма, список, таблица статистики
- `style.css` — оформление
- `app.js` — состояние, расчёты, отображение

## Ответы на вопросы

**Где хранятся исходные данные?**
В одном массиве `values` в файле `app.js`. Это единственный источник правды — все числа лежат только там, а не в HTML.

**Почему показатели лучше вычислять из массива, а не хранить отдельно?**
Потому что иначе легко получить рассогласование: число добавили, а сумму забыли обновить. Здесь массив — единственный источник, а сумма, минимум, максимум и среднее всегда пересчитываются в `getStatistics()` на его основе.

**Что возвращает getStatistics()?**
Объект вида `{ count, sum, min, max, average }`. Для пустого массива — `count: 0`, `sum: 0`, а `min`, `max`, `average` равны `null` (эти величины не определены).

**Как программа обрабатывает пустой массив?**
`getStatistics()` для пустого массива возвращает `null` для min/max/average. Функция `render()` проверяет эти значения и выводит «—» вместо NaN или Infinity. Для count и sum выводится 0.

**Какое место в программе было сложнее всего отладить?**
Проверка ввода и обработка пустого массива — именно там чаще всего появлялись NaN и Infinity. Решение: `Number.isFinite(value)` для проверки числа и явное условие `values.length === 0` в `getStatistics()`.
