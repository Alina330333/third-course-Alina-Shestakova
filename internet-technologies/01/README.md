# Лабораторная работа 1. Как работает веб-приложение

## Файлы
- `index.html` — структура страницы
- `style.css` — оформление
- `app.js` — логика счётчика

## Ответы на вопросы

**Где в программе хранится состояние?**
В одной переменной `value` в файле `app.js`. Все изменения числа происходят только с ней.

**Какая функция обновляет интерфейс?**
Функция `render()`. Она читает текущее значение `value` и обновляет текст на странице и сообщение о знаке числа.

**Какие события обрабатываются?**
События `click` (нажатие) на трёх кнопках: `+1`, `-1`, `Сброс`. Для каждой кнопки свой обработчик.

**Что произойдёт, если изменить значение переменной, но не вызвать функцию обновления интерфейса?**
Переменная в памяти изменится, но пользователь не увидит изменений на странице — интерфейс (DOM) не обновится. Именно `render()` «переносит» новое значение из переменной в HTML.
