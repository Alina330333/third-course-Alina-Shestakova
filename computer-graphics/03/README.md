# Лабораторная работа 3. Растеризация окружности

## Ответы на вопросы

**Как используется симметрия окружности?**
Если для окружности найдена точка `(x, y)`, то из неё симметрией получается ещё семь: `(y, x)`, `(-x, y)`, `(-y, x)`, `(x, -y)`, `(y, -x)`, `(-x, -y)`, `(-y, -x)`. Функция `plot8` строит все восемь точек сразу.

**Почему достаточно строить одну восьмую?**
Из-за восьмикратной симметрии. Достаточно посчитать точки от `x = 0` до границы `x = y` — это ровно одна восьмая окружности. Остальное восстанавливается отражениями.

**Что означает переменная d?**
Это решающая величина — аналог ошибки у Брезенхема. По её знаку выбирается следующий пиксель: если `d < 0` — берём `E = (x+1, y)`, иначе `SE = (x+1, y-1)`.

**Когда уменьшается y?**
Когда `d >= 0`, то есть средняя точка оказалась не внутри окружности, а на границе или снаружи. Тогда берём вариант `SE` и уменьшаем `y` на 1.

**Почему цикл заканчивается при x > y?**
Мы строим только сектор от верхней точки до направления 45°. На границе `x = y`, дальше точки уже дублируют построенные через симметрию. Продолжать бессмысленно.

**Совпали ли пиксели средней точки и способа через формулу?**
В большинстве случаев да. На некоторых радиусах возможны расхождения в 1 пиксель — оба варианта «правильные», по-разному округляют. Средняя точка даёт более равномерный набор.

**Что показал эксперимент по времени?**
На одном запуске разница почти незаметна. При серии из 1000 построений алгоритм средней точки обычно быстрее: в нём нет `sqrt` и вещественных вычислений, только сложение, вычитание и сравнение.
