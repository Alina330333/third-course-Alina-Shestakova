# Лабораторная работа 5. Заполнение областей

## Как запустить
Открыть `index.html` в браузере (можно через Live Server).

## Как задается многоугольник
Многоугольник задан массивом вершин в `app.js`. Используется невыпуклый многоугольник:
`[{x:5,y:5}, {x:25,y:5}, {x:25,y:15}, {x:15,y:15}, {x:15,y:25}, {x:5,y:25}]`.

## Как хранится логический растр
Используется одномерный массив `grid` размером 40x30 (1200 элементов). 
- `0` (EMPTY) — пустая клетка
- `1` (BORDER) — контур
- `2` (FILLED) — закрашено
Canvas лишь отрисовывает этот массив.

## Связность
В Flood Fill используется **4-связность** (верх, низ, лево, право). Диагонали не используются.

## Правило обработки вершин в Scanline
Чтобы не считать вершину дважды, мы проверяем пересечение ребра со строкой `scanY` по правилу: `yMin <= y < yMax`. Нижняя граница включается, верхняя — нет. Горизонтальные ребра пропускаются.

## Результаты обязательных тестов
- Прямоугольник: заливается корректно обоими алгоритмами.
- Треугольник: заливается корректно.
- Выпуклый многоугольник (5+ вершин): заливается корректно.
- Невыпуклый многоугольник (текущий в коде): заливается без выхода за границы.
- Горизонтальное ребро: Scanline Fill пропускает его, но контур отрисовывается.
- Строка через вершину: благодаря правилу `yMin <= y < yMax` учета двойного пересечения не происходит.
- Flood Fill со стартом внутри: заполняет область.
- Flood Fill со стартом снаружи: заполняет всё внешнее пространство вокруг контура.
- Незамкнутый контур: Flood Fill «вытекает» наружу (заполняет всю область до краев сетки). Scanline Fill заливает многоугольник так, будто он замкнут.

## Сравнение Flood Fill и Scanline

| Метод | Нужна стартовая точка | Использует список вершин | Что обходится |
| :--- | :--- | :--- | :--- |
| **Flood Fill** | Да (клик мыши) | Нет | Соседние пиксели (через стек) |
| **Scanline Fill** | Нет | Да | Строки и ребра (через геометрию) |

**Вывод:** 
- Flood Fill удобен для заливки произвольных областей, ограниченных контуром, но требует наличия стартовой точки.
- Scanline Fill работает быстрее для многоугольников, так как использует формулы, но требует строгого списка вершин.
- При разрыве контура Flood Fill «протекает» во внешнюю область, а Scanline Fill продолжает заливать внутренность многоугольника, так как опирается на координаты вершин.
