# Лабораторная работа 7. Клиент и собственный API

## Установка и запуск
1. `npm install`
2. `npm start`
3. Откройте `http://localhost:3000`

## Структура проекта
- `server.js` — бэкенд на Express, отдает статику из `public` и API.
- `public/` — фронтенд (index.html, style.css, app.js).
- `data.db` — база SQLite (создается автоматически).

## Схема обмена
Браузер `fetch()` → Express-роут → SQL-запрос → SQLite → JSON-ответ → обновление `tasks[]` → `render()` → DOM.

## API-маршруты
- GET `/api/tasks` — получить список
- POST `/api/tasks` — создать
- PATCH `/api/tasks/:id` — изменить (например, переключить `done`)
- DELETE `/api/tasks/:id` — удалить

## Действия в интерфейсе
- Добавление новой задачи.
- Клик по задаче меняет её статус (выполнено/не выполнено).
- Удаление задачи.
- Обновление списка кнопкой.

## Проверка ошибок
- 400: при попытке отправить пустое поле (проверяется и на клиенте, и на сервере).
- 404: при попытке изменить/удалить несуществующую задачу.

## Сохранение данных
Задачи сохраняются в SQLite. При перезапуске сервера данные не пропадают.

## Безопасность
Для вывода текста используется `textContent`, а не `innerHTML`. Если ввести `<b>текст</b>`, он отобразится как текст, а не как жирный шрифт. Это защищает от XSS-атак.
