# Лабораторная работа 6. Отсечение многоугольника (Сазерленд-Ходжман)

## Запуск
Откройте `index.html` в браузере.

## Способ задания многоугольника
Многоугольник задан массивом вершин в `app.js` (невыпуклый, в форме угла/молнии).
`[{x:5, y:5}, {x:25, y:5}, {x:25, y:15}, {x:15, y:15}, {x:15, y:25}, {x:5, y:25}]`

## Параметры окна
По умолчанию: `xmin=10, ymin=10, xmax=30, ymax=20`.

## Таблица четырёх переходов
| S (было) | P (стало) | Действие |
| :--- | :--- | :--- |
| внутри | внутри | добавить P |
| внутри | снаружи | добавить точку пересечения |
| снаружи | внутри | добавить пересечение и P |
| снаружи | снаружи | ничего не добавлять |

## Формулы пересечения
Для вертикальной границы (x = bound):
`t = (bound - a.x) / (b.x - a.x)`
`y = a.y + t * (b.y - a.y)`

Для горизонтальной границы (y = bound):
`t = (bound - a.y) / (b.y - a.y)`
`x = a.x + t * (b.x - a.x)`

## Ручной расчёт
Возьмем ребро от `S(5, 5)` до `P(25, 5)` при отсечении по левой границе `x=10`.
- S находится снаружи (x=5 < 10).
- P находится внутри (x=25 >= 10).
- Это переход outside -> inside. Нужно найти пересечение и добавить P.
- Считаем `t = (10 - 5) / (25 - 5) = 5 / 20 = 0.25`.
- `y = 5 + 0.25 * (5 - 5) = 5`.
- Точка пересечения: `(10, 5)`.
- В выходной массив добавляются: `(10, 5)` и `(25, 5)`.

## Результаты обязательных тестов
- **Полностью внутри**: (12, 12) -> (28, 18) — сохраняется.
- **Полностью снаружи**: (2, 2) -> (8, 8) — результат пуст (0 вершин).
- **Пересекает одну границу**: (5, 5) -> (15, 15) — отсекается по левой.
- **Пересекает все четыре**: Большой квадрат (-10, -10) -> (50, 50) — отсекается до размеров окна.
- **Невыпуклый**: текущий тестовый многоугольник отсекается корректно.
