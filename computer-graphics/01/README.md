## Ответы на вопросы

**Что такое растеризация?**
Это процесс преобразования геометрического объекта (например, математического отрезка) в набор дискретных пикселей растра. Экран состоит из клеток, поэтому непрерывную линию нужно заменить подходящим набором пикселей.

**Зачем в ЦДА выбирается max(|dx|, |dy|)?**
Это количество шагов вдоль самой длинной оси. Если взять меньше шагов, вдоль длинной оси появятся «дыры» между пикселями и линия будет разрывной. Ось с большим изменением задаёт число итераций, а по второй оси приращение получается меньше единицы.

**Почему координаты приходится округлять?**
Потому что в ЦДА x и y меняются на дробные величины (xStep, yStep), а пиксель на экране имеет целые координаты. Округление `Math.round()` выбирает ближайшую клетку растра.

**Что произойдёт, если начало и конец отрезка совпадают?**
Тогда `dx = 0`, `dy = 0`, `steps = 0`. Деление на ноль недопустимо, поэтому в коде есть отдельная проверка: рисуется ровно один пиксель в этой точке.

**Какие недостатки ЦДА вы заметили?**
- Использует вещественные числа (x, y, xStep, yStep).
- На каждом шаге выполняется деление.
- Требуется округление.
- При большом количестве шагов накапливается погрешность из-за сложения дробных чисел.

## Проверенные случаи
- (2, 2) → (20, 8)
- (20, 8) → (2, 2)
- (5, 2) → (5, 20)
- (2, 10) → (25, 10)
- (3, 20) → (12, 2)
- (8, 8) → (8, 8)
