# Лабораторная работа 8. Основы 3D-графики

## Запуск
Откройте `index.html` в браузере.

## Система координат и камера
- Правая система координат.
- Камера находится в начале координат `(0,0,0)` и смотрит вдоль оси Z (положительные значения Z находятся перед камерой).
- Ось X направлена вправо, ось Y — вверх (на Canvas Y инвертирована).

## Исходные данные
**Куб:**
- Вершины: от `(-1,-1,-1)` до `(1,1,1)`.
- Рёбра: 12 штук.

**Пирамида:**
- Вершина в `(0, 1.5, 0)`.
- Основание — квадрат на уровне `y = -1`.

## Матрицы поворотов
Для угла θ, где `c = cos(θ)`, `s = sin(θ)`:
- **Rx:** `[1,0,0; 0,c,-s; 0,s,c]`
- **Ry:** `[c,0,s; 0,1,0; -s,0,c]`
- **Rz:** `[c,-s,0; s,c,0; 0,0,1]`
(Матрицы расширены до 4x4 с единицей в правом нижнем углу).

## Порядок преобразований
`P_world = T * Rz * Ry * Rx * S * P_local`
То есть сначала масштаб, потом повороты X, Y, Z, и в конце перенос вдоль Z.

## Формулы проекций
**Ортографическая:**
`x_screen = width/2 + x * scale`
`y_screen = height/2 - y * scale`

**Перспективная:**
`x_screen = width/2 + f * x / z`
`y_screen = height/2 - f * y / z`
(где `f` — фокусное расстояние).

## Ручной расчёт
Возьмем точку `P = (1, 1, 1)`, масштаб `S=1`, поворот `Y=45°`, `Z=6`.
`R_y` для 45°: `cos(45) ≈ 0.707`, `sin(45) ≈ 0.707`.
`x' = 1 * 0.707 + 1 * 0.707 = 1.414`
`y' = 1`
`z' = -1 * 0.707 + 1 * 0.707 = 0`
`P_world = (1.414, 1, 0 + 6) = (1.414, 1, 6)`
При перспективной проекции с `f=300`:
`x_screen = 300 + 300 * 1.414 / 6 = 300 + 70.7 = 370.7`
`y_screen = 225 - 300 * 1 / 6 = 225 - 50 = 175`

## Отсечение по ближней плоскости
Если `z <= near` (где `near = 0.1`), точка невидима. Если ребро пересекает эту плоскость, мы вычисляем точку пересечения `t = (near - a.z) / (b.z - a.z)` и обрезаем ребро. Это предотвращает деление на ноль и вылет линий за пределы экрана при приближении.
